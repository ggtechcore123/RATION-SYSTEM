National PDS Architecture Pillars

Zero leakage, eliminate phantom beneficiaries, and enforce precision weighing.

🔒

Hyperledger Fabric Ledger

Every grain batch, from farmer procurement to warehouse transit and final beneficiary distribution, is immutably committed on-chain with cryptographic SHA-256 state proofs.

👆

ESP32 IoT Biometric POS

Local fingerprint matching via optical sensor and 4x4 matrix keypad prevents biometric image leaks while guaranteeing that only authorized family members collect rations.

⚖️

Family Entitlement Rules

Automated calculation according to NFSA rules: Priority Households (PHH) receive per-person quotas, while Antyodaya Anna Yojana (AAY) households receive fixed allocations.

Smart Indian Public Distribution System (PDS)

National e-Governance Division project designed to revolutionize the Targeted Public Distribution System (TPDS). Built with Node.js, Firebase Firestore, Hyperledger Fabric Blockchain, and ESP32 IoT biometric POS terminals.
